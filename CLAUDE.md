# Claude Code entry point

Read [AGENTS.md](AGENTS.md) and [desktop-agent workflow](docs/desktop-agent-workflow.md) before planning or rendering a video. Act as the director in the desktop session: author the plan and revision requests as files, call the local CLI, and inspect the rendered output. No LLM API key is required by this repository.

Own setup and command execution. The user supplies the creative request and source files; do not ask them to prepare JSON or operate the CLI.
