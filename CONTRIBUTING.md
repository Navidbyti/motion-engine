# Contributing

Open issues with a reproducible input, expected output, target application/version, and the smallest MotionSpec that shows the problem. Do not upload confidential customer files; replace them with synthetic examples. Pull requests should update the schema and migration notes when contracts change, include tests for at least two different fixture types where applicable, and state any editability limitations. Run `python -m pytest` before submitting. Native Adobe adapter changes require a tested version matrix and open-save-reopen evidence.
